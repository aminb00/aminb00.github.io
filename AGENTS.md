# AGENTS.md

Personal site of Amin Borqal: Astro 7, static output, plain 1990s-style HTML.
`BRIEF.md` is the brief (the source of truth for content and rules),
`PLAN.md` the approved plan, `README.md` the how-to.

## Commands

```
npm ci
npm run dev        # http://localhost:4321
npm run build      # scripts/docs.mjs (PDF to images), astro build, scripts/check.mjs
npm run preview
npm run links      # lychee, internal links and anchors
npm run verify     # Playwright with the installed Chrome; BASE=http://localhost:4321
npm run shots      # screenshots at 375, 768, 1280 px
npm run fetch      # download source PDFs, scan them for personal data
npm run icons      # favicon and Open Graph image
```

System tools: poppler (only for new or changed PDFs), lychee, Google Chrome.
Node 26 (`.nvmrc`).

## Where things are

- Content: `src/data/*.yaml`, schemas in `src/content.config.ts`. Slug
  registry and cross-link checks: `src/lib/site.ts`.
- Pages `src/pages/`, components `src/components/`, browser scripts
  `src/scripts/` (viewer, filter, email), styles `src/styles/site.css`
  (inlined by `src/lib/css.ts`).
- PDFs in `public/pdf/` (each under 20 MB). Slide images and posters in
  `public/slides/<id>/`, generated by `scripts/docs.mjs` and committed.

## Rules (from BRIEF.md; `scripts/check.mjs` enforces what it can)

- Never invent facts, numbers, dates, links, titles. A missing value is `TODO`
  in the data and stays off the page.
- Verbatim texts (bio, experience bullets, fields marked `*Verbatim: true`)
  are never edited. They render inside `data-verbatim` elements.
- No en dash or em dash anywhere; none of the banned words (list in
  `scripts/check.mjs`) outside `data-verbatim`.
- No phone number, street address or grades. The email appears in HTML only as
  `user [at] domain [dot] com`; JS assembles the link.
- No JS framework, no web fonts on desktop, no third-party requests, no
  analytics. Every page under 100 KB without images.
- Look: white page, black serif, blue underlined links, `<hr>` between
  sections, native buttons. No gradients, shadows, rounded cards, emoji,
  animations.
